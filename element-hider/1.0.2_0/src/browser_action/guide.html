How-to Guide

Your guide to a cleaner, quieter web.

Getting Started: Main Controls

Hiding Active (On/Off)

This is the master switch in the popup. When "On", the extension will actively hide elements based on your rules. When "Off", all hiding is disabled.

Test Mode

Instead of hiding elements, Test Mode highlights them in bright green. This is perfect for safely checking what your rules will affect without making things disappear.

Adding Hiding Rules

1. Add Keyword Manually

Type a word into the input box and click the + button. Use the checkboxes for "Exact Match" or "Case Insensitive" as needed.

2. Add CSS Selector

For targeting specific parts of a page layout. Type a CSS selector (e.g., div.advert), check the "CSS Selector" box, and click +.

3. Use the Word Selector Tool

Click the "Select Word" tool in the popup. On any webpage, hover to highlight words and click to confirm. The popup will open with your selected word ready to be saved.

4. Use the Element Selector Tool

For hiding specific page sections like sidebars or ad boxes. Click the "Select Element" tool, then click any part of a page. A dialog will help you create a precise hiding rule for it.

Display & Hiding Options

These settings can be found in the Advanced Config page, which you can open by clicking the gear icon ⚙️ in the popup.

Original Blurred

Blur Instead of Hiding

Instead of making elements disappear completely, you can choose to blur them. This is useful if you occasionally want to see the content.

Reveal on Hover

This option only works when "Blur" is active. When you move your mouse over a blurred element, it will become clear, allowing you to read it.

Hiding Sensitivity (Global vs. Keyword)

This slider (1-500) controls how large of an area around a found keyword gets hidden. A low value is cautious, while a high value is aggressive and hides a larger parent container.

You can set this globally in the Advanced Config, or set it for an individual keyword using its "Advanced Options" in the popup. A keyword-specific sensitivity will always override the global setting.

Global Site Settings

In the Advanced Config page, you can control which websites the extension runs on.

Disable on Sites Below (Blacklist)

The extension will run on all websites except for the ones you list in the text box. Use this to exclude sites where you don't want hiding to occur.

Enable ONLY on Sites Below (Whitelist)

The extension will only run on the websites you list in the text box. Use this if you only need the extension for a few specific sites.

For Power Users: Bulk Editing & Syntax

Bulk Edit

Click the "Bulk Edit" tool (pencil icon) to see a raw text version of your keyword list. You can quickly add, remove, or copy-paste many rules at once. Each rule must be on a new line.

Keyword Syntax Reference

When bulk editing, you can use the following syntax:

// This is a comment and will be ignored.

keyword - Hides any element containing this text.

*keyword - (Exact Match) Hides only the whole word.

keyword^ - (Case Insensitive) Hides "keyword", "Keyword", "KEYWORD", etc.

*keyword^ - You can combine options.

{div.advert} - Hides elements using a CSS selector.

Advanced Rule Format: keyword >>> [URL] &&& [Sensitivity]

The >>> marker indicates that advanced rules follow. The URL always comes first, then sensitivity. If the URL is blank, the space is preserved.

sports >>> reddit.com - Hides "sports" only on reddit.com.

news >>> &&& 75 - Hides "news" on all sites with a specific sensitivity of 75.

politics >>> cnn.com &&& 250 - Hides "politics" only on cnn.com with a high sensitivity of 250.
